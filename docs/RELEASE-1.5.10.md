# ConnectorWatch 1.5.10

The confidence chart now reconnects a saved comparison from an older driver
when the GPU UUID differs only in letter case. The previous selection could
match no restored rows and incorrectly display that it needed three days.

The app keeps the selected load bin and uses its existing historical scores.
The accepted baseline, model, telemetry, and scoring rules stay unchanged.
Sparse completed days still show their actual evidence status.

Download **ConnectorWatch-Setup-1.5.10.exe** to update. The saved comparison is
mapped automatically when the history loads.
