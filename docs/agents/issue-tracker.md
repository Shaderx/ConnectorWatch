# Issue tracker: GitHub

Issues and specifications live in Shaderx/ConnectorWatch GitHub Issues. Use `gh`
from this checkout; resolve the repository from its remote.

Read an issue with `gh issue view <number> --comments`; list with `gh issue list`.
For authorized publication, use `gh issue create` or `gh issue comment` with
`--body-file` for multiline text. Use `gh issue edit` for labels and `gh issue close`
for completion. User authorization is required before posting messages to others.

**PRs as a request surface: no.**

When a skill says to fetch a ticket, read its GitHub issue and comments. When it
says to publish to the tracker, create the issue within the authorized scope.
